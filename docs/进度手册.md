## 5. 还开着的缺陷与限制（已修项不在此列，见 CHANGELOG）

1. **R1**（空参数名变形语义）与 **R2**（D3 参数无 UI）——WAF 模块仅有的两条已知缺陷级欠账。
2. **无真机线**：Windows 全族（R3）、低 JDK（R4）、AD 靶域（R5）；相关能力一律标「未验证」，
   不用桩或推断替代结论。
3. 环境事实：GitHub **设备流端点对 gh CLI 公开 client_id 返回 404**（代理下实测），gh 授权只能
   token 递送；`github.com` 网页域名不挂代理时常超时，`api.github.com`/SSH 正常。
4. 自检脚本的「带令牌访问」项是可选检查：过期令牌文件会造成假 FAIL（已改为无文件即 SKIP），
   `/tmp/jw.token` 旧文件已移走备份。
5. 统计数字为收口时点（R11）；HBC 门禁未解（R7）。
