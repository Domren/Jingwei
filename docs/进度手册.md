**结论**：已覆盖能力全部 PASS；揪出并修复 2 处缺陷；未测项均为 LLM/外部服务/靶机条件缺失，
已明确标注而非用桩冒充。

**矩阵摘要**：

- **1.5.0**：弱口令（6 协议 hit/deny）、显式端口目标、增量 diff（修复后）、对外交付导出
  （client-md/md-zip）、目录枚举+JS URL 提取、授权清单与范围审批、guard 拒绝统计、
  内网脚本库、撤离残留扫描与痕迹矩阵、运维事件通知 —— 全 PASS。
- **1.6.0**：断点续扫 + 增量 diff、隧道并发预算、exec-form 三语境换算、密钥轮换自检与补救、
  撤离痕迹矩阵、子域名枚举、终端防护识别（Linux）、浏览器 XSS 真执行、凭据复用批次、
  Java 内存马（v2 父壳→auto 选型→check/exec→删除）、IPv6 字面量目标、WAF 自适应绕过、
  MCP 托管 —— 全 PASS。

**本轮揪出并修复的 2 处缺陷**（已随 **1.6.1** 发布，见 CHANGELOG `[1.6.1]` 「修复」）：

1. **增量 diff 空列表序列化为 null 导致前端白屏**：`computeScanDiff` 无新增/消失/严重度变化时
   返回 nil 切片，JSON 落成 `null`，前端 `diff.new.length` 抛 TypeError。修复：三个列表初始化
   为非 nil 空切片，恒序列化 `[]`。夹具：`TestScanDiffEmptyListsMarshalAsArrays`。
2. **对外交付导出因空正文 blob 缺失整体失败**：GET 请求体长度 0，blob 哈希恒为空串 SHA256；
   容器重建抹掉 `/app/data/evidence` 后该 0 字节 blob 不存在，`copySnapshots` 一律报错拖垮导出。
   修复：对「长度 0 + 空正文哈希」直接还原 0 字节文件（内容可由哈希无损校验），非空正文缺失
   仍报错以保证证据完整性。夹具：`TestCopySnapshotsRecoversMissingEmptyBody`。

**回归**：`go build ./...`、`gofmt`、`go vet ./server/... ./evidence/...`、
`staticcheck ./server/... ./evidence/...`（仅预存告警，无新增）、
`go test ./server -run TestScanDiff`、`go test ./evidence` 全部通过。
