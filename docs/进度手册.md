**本轮揪出并修复的 2 处缺陷**（已进 CHANGELOG [Unreleased] 「修复」）：

1. **增量 diff 空列表序列化为 null 导致前端白屏**：`computeScanDiff` 无新增/消失/严重度变化时
   返回 nil 切片，JSON 落成 `null`，前端 `diff.new.length` 抛 TypeError。修复：三个列表初始化
   为非 nil 空切片，恒序列化 `[]`。夹具：`TestScanDiffEmptyListsMarshalAsArrays`。
2. **对外交付导出因空正文 blob 缺失整体失败**：GET 请求体长度 0，blob 哈希恒为空串 SHA256；
   容器重建抹掉 `/app/data/evidence` 后该 0 字节 blob 不存在，`copySnapshots` 一律报错拖垮导出。
   修复：对「长度 0 + 空正文哈希」直接还原 0 字节文件（内容可由哈希无损校验），非空正文缺失
   仍报错以保证证据完整性。夹具：`TestCopySnapshotsRecoversMissingEmptyBody`。

## 6. 真机清单（R3/R4/R5 代码侧已闭环，需真机确认）

### R3 · Windows OpenSSH 靶机
- **主机**：Win10/11 或 Server 2019+ 一台，装好 OpenSSH Server（`Add-WindowsCapability OpenSSH.Server`）
- **两条会话**：ForceCommand 分别设为 `C:\Windows\System32\cmd.exe` 和 `C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe`
- **四组验证点**（每组同时跑 cmd / PS 会话，对照比）：
  1. 7 条信息收集脚本（win-systeminfo / win-users / win-admins / win-ports / win-patches / win-endpoint / win-tasks）
  2. upload 一个二进制到 `C:\temp\payload.bin`（gzip 压缩和不压缩各一次，校验大小一致）
  3. download 回源同一个文件
  4. 维持一组（schtasks 或 startup 文件夹）deploy → verify → revoke
- **夹具钉点**：`TestPowerShellSSHTransportNeverSeesCmdScripts`（守卫仍拦截操作人 cmd 命令）。
  **待补钉**：「平台在 PS 会话上生成的上传命令确为 PS 语法」目前**没有**对应夹具——真机回归时补，
  别在没有测试的情况下宣称已钉住。

### R4 · 低版本 JDK 三容器
- **三台容器**：`eclipse-temurin:8-jre` / `eclipse-temurin:11-jre` / `eclipse-temurin:17-jre`，各跑一个 Tomcat 容器
- **Sidecar**：javachains sidecar（`deploy/java-chains-setup.sh` 脚本）+精卫 server 都放进同一个 docker-compose 网络
- **验证点**：每个靶机跑一遍 `kind=java_deser` 深度利用任务，抓 `outcome` 字段，填进规划表「已验证」列。关键结论是哪些 gadget 链在低 JDK 上**退化到探测/回显**或**直接失败**（只有 `outcome=exec` 算完封）

### R5 · AD 靶域
- **域控**：一台 Samba AD DC（`docker run -p 389:389 -p 636:636 -p 88:88 -p 445:445 --hostname dc.jingwei.local -e REALM=JINGWEI.LOCAL jumanjihouse/samba-ad-dc`）或直接 Windows Server 装 AD DS 角色
- **精卫挂进同网络**：能访问 LDAP (389) / GC (3268) / Kerberos (88) / SMB (445)
- **两条链路**：
  1. topology：从 LDAP `trusts` 条目解析信任域，`ExplorationStore.Link(dc, "trusts", otherDC)`
