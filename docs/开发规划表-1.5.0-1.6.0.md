## 3. 明确不做

多用户与角色、任务归属与交接、审批流、协作视图、Web 界面重写、白盒代码审计（除「从源码/配置提取
凭据」服务横向的形态）、商业验证码协议（极验/易盾明确报不支持）、空间测绘 API（负责人决定：不接
provider、不索密钥）、**任何规避终端防护/杀软的能力**。将来真要多人：一人一实例 + 数据导出。

## 4. 排期硬规则（不变的两条）

1. 每个功能条目落地时同步加 `tools/e2e/` 项数，并在 CHANGELOG「验证」写明在哪个靶机验的——断不得。
2. 含安全修复一律走新小版本、不移动已发布标签；功能版本才动 minor。
